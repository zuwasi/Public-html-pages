A frontier model is the engine; the agent harness is the rest of the car — the transmission, steering, and driver. Give two agents the identical model and task, and the better harness wins on time and dollars while matching quality. (The Kaggle “New SDLC with Vibe Coding” whitepaper argues the harness carries the overwhelming share of outcome — our results are consistent with that.)

Experiment 01 · the hard domain
Quantum-compilation optimization
Qubit routing / SWAP — NP-complete Magic-state scheduling — NP-hard Tensor-network contraction — NP-hard Pulse / GRAPE — optimal control

Amp in a basic mode beat Claude Code + Claude Fable 5 at max effort: correct solutions, faster, at a fraction of the cost — full run correctness 1.000 for $4.59.

“If a basic agent solved it easily, maybe it wasn’t worth using Fable Max?” — Claude Fable 5.

We asked: “Are you sure QMAP is basic? Check again.” It conceded — qubit routing is NP-complete. The “basic” harness had quietly solved a hard problem, cheaper and faster.
