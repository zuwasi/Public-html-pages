02 · Before you start

Toolchain

  • Visual Studio 2026 with C++ and CUDA Toolkit MSBuild integration.
  • NVIDIA CUDA Toolkit 13.x and a supported project configuration.
  • Parasoft C/C++test Professional 2026.1 with an active license.
  • CMake for CMake-folder projects.

Bridge authorization

  • A signed, machine-bound ESL activation token.
  • Stage 1 provides 30 days from first successful activation.
  • Stage 2 adds its own 30-day period when activated; stage 3 is permanent.
  • Unit tests and host coverage additionally require C/C++test Standard and GoogleTest.

The Bridge does not supply or extend Parasoft entitlements, CUDA Toolkit licensing, or Visual Studio licensing.

08 · Scope and limitations

Know what the workflow does and does not cover

Analysis
  • Host-visible CUDA code is analyzed through companion projects.
  • The workflow is not native CMake engine integration.
  • CUDA source checks are heuristic, not full semantic proof.
Tests and coverage
  • CUDA GoogleTest supports native Visual Studio projects with adjacent tests.
  • CMake-folder test discovery is not supported.
  • Host coverage does not instrument device-kernel code.
CUDA guideline rules are not MISRA rules. Neither a clean scan nor a coverage percentage is certification or proof of safety compliance.
