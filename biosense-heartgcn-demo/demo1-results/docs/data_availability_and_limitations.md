# Data availability and limitations

The paper reports 16 swine datasets, a shape model from 11, 213 generated anatomies, 10,650 simulations, and five held-out swine geometries (pp. 4–5). These assets, source code, network weights, exact split, mesh topology, fibers, preprocessing bounds, ECG features, and high-density contact maps were not supplied with this task and no paper repository is identified in the article.

Consequently this project can verify published equations and construct deterministic synthetic graph experiments, but cannot reproduce the 20-layer trained model, Figs. 3–6 numerically, the reported 8 ms/7 ms MAEs, or any clinical/generalization conclusion. The rectangular graph is not cardiac anatomy. Harmonic interpolation does not embody the learned physiological prior. Noise sweeps are sensitivity demonstrations, not confidence intervals. Zero-speed scar is represented as an impassable edge; the paper does not state its software convention.

The source PDF is read-only evidence and is not modified. The extracted text is an OCR aid; equation interpretations were checked against surrounding prose and recorded in the issue ledger.
