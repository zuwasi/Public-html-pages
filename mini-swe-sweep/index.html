Cost estimates: how they were computed

  • Per-session wall time is exact (measured by the harness, shown per row). Token counts are not exposed by either CLI, so cost is estimated from wall time.
  • Opus-class sessions (both arms of run 2, and Claude Code in run 1): estimated at 4-7 dollars per hour of wall time. Assumes ~3M input tokens/hour (mostly cache reads billed near 10%), ~40k output tokens/hour, at roughly $5 per M input and $25 per M output. Treat as order-of-magnitude.
  • Amp low mode (run 1 only): estimated at 0.5-1.5 dollars per hour (budget-tier model, cheaper per token).
  • Run 2 estimate total: Amp arm $28-$48 + Claude arm $13-$23 (Claude figure would roughly double once the 6 truncated repos are rerun with full caps). Run 1 estimate total: Amp low $1-$2 + Claude $7-$11.
  • Amp subscription plans bill separately from metered API; if sessions run inside a subscription the marginal cost can be zero, but the metered-equivalent estimate above is what the work would cost on pay-per-token.

Observations

  • These behavioral bugs are hard for both agents: the best full-run score on any repo is 1/5 (20%), consistent with SWE-sweep difficulty.
  • Same model, six valid repos: Amp's harness resolved 2 bugs vs Claude Code's 1, with fewer graded regressions (run 1's Claude roslyn diff introduced 22 regressions and was zeroed by the gate).
  • Amp sessions typically used the time budget fully; Claude Code sessions in this benchmark either finished early with small diffs or died to quota. Session durations per row above.
  • Operational lesson: quota interruptions invalidated 3 of 5 Claude batch attempts. For agent benchmarks, budget the plan limit, not just the tokens.
