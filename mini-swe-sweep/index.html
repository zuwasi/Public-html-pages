Method

Both agents received the identical SWE-sweep instruction: find and fix 5 reference bugs in a repository checked out at a frozen upstream release, in 1 hour, fully autonomous (no human input). Each agent's diff is then scored by the SWE-sweep Docker verifier against hidden regression tests for each of the 5 bugs, plus visible-test regression checks. A bug counts only when the hidden test passes; introduced regressions are reported. Both arms ran the same underlying model, claude-opus-5-5, so the only variable is the agent harness: Amp (default mode, sandboxed orchestrator) versus Claude Code (headless -p mode).

Early observations (pending final Claude batch-3 numbers)

  • Both agents find these behavioral bugs hard: the best full-run score on any repo is 1/5 (10-20%), consistent with SWE-sweep's overall difficulty.
  • Same model, six valid repos: Amp's harness resolved 2 bugs where Claude Code's resolved 1, and Amp produced fewer graded regressions.
  • The verifier's regression gate matters: run 1's Claude roslyn diff passed visible tests but introduced 22 regressions, zeroing its reward.
  • Quota interruptions are a real operational cost of agent benchmarking: three of five Claude batch attempts were invalidated by a monthly spend limit. Budget the quota, not just the tokens.
