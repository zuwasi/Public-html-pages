You just saved a screenshot. Amp needs the path, not the pixels.

SavePathCopier is a tiny Windows tray utility: every time you save a file, its full path lands on your clipboard. Save, paste, done — Amp knows exactly which file to open.

The problem it solves

An AI coding agent like Amp cannot see your screen. It also cannot peek into your folders on its own. What it can do is read any file on your machine — a screenshot, an error dialog capture, a log, a PDF — the moment you tell it where that file is.

The problem: in many Amp workflows (terminal sessions, quick questions, inputs without image paste support) you cannot paste a picture at all. The practical bridge between your screen and the agent is the file path. And typing C:\Users\danie\OneDrive\Desktop\Screenshot 2026-10-31 125117.png by hand is exactly the kind of chore nobody wants.

The workflow, in four steps

1. SaveScreenshot, export, document — save it anywhere you normally would (Win+Shift+S, Save As...).→
2. Path is copiedSavePathCopier puts the full path on your clipboard automatically. No click, no typing.→
3. Paste into AmpCtrl+V in the Amp prompt. Or Win+V to pick an earlier saved file from clipboard history.→
4. Amp reads itAmp opens the file at that path — image, log, PDF, code — and answers with full context.

Why pasting the path beats everything else

Zero typing

Long OneDrive paths, timestamps in screenshot names — copied perfectly every time, no "which folder was it again".

Works everywhere

A path is plain text: paste it into the Amp CLI, a chat box, a config file, an issue, or a script.

Any file type

Screenshots, PDFs, Excel exports, stack-trace logs, design mockups — Amp opens and analyzes all of them.

Built-in history

Win+V keeps your recent saved-file paths, so "the dialog from ten minutes ago" is still one paste away.

What it looks like in practice

You: Why is this dialog showing an empty table? C:\Users\danie\OneDrive\Desktop\Screenshot 2026-10-31 125117.png
Amp: Opens the screenshot, sees the grid has zero rows and a red status bar, then reads your service code and finds the query returning nothing — and proposes the fix.
You: This build log looks wrong, check the last 50 lines: C:\tmp\build-output.log
Amp: Greps the log, finds the linker error, and explains which missing symbol caused it.

What it watches

By default: your Desktop, Documents, Downloads and C:\tmp, including subfolders. Office lock files and browser temp downloads are ignored, so autosave noise never floods your clipboard. Edit one text file to add any folder.

Install in under a minute

Runs at logon as a tray app. No admin rights, no dependencies, no typing of paths.
