How this page was made

This page was produced by an AI coding agent from two prompts. The prompts are quoted below with spelling corrected.

Scan the website https://www.anthropic.com/careers/jobs and look for software engineering jobs that involve programming skills. Extract them and create a list of the skills I need to have if I trust Anthropic as the market leader and the main influencer. Rate them with scores and percentages, and create a chart in HTML.
Upload it to our public web pages with explanations of the prompt and what we have done.

What we did

  1. Collected every open posting. The careers page loads its jobs from Anthropic's public Greenhouse job board. Its API returned all open postings with full descriptions.
  2. Kept the hands-on software roles. We kept titles containing "Engineer" whose description asks for programming: a language, coding, or software engineering. We removed managers and directors, plus datacenter, manufacturing, hardware, AV, IT support and physical security roles. Roles posted in several locations were counted once. That left roles.
  3. Removed shared boilerplate. Every posting repeats the same company intro, compensation and logistics text. We stripped it so it would not inflate any skill.
  4. Matched skills. Each skill has a keyword pattern, for example "Rust" or "distributed systems"; of them appear in at least one role. The skills are grouped into 8 areas: languages, AI/ML, systems & infrastructure, data, web/product, security, engineering practice and mindset.
  5. Scored by importance. A mention under required qualifications counts 1.0, in the role description 0.75, and under nice-to-have 0.5. A skill counts once per job, at its strongest weight. The highest total is scaled to 10. % is the share of roles that mention the skill at all.
  6. Checked the matches by hand. Sample matches were read to catch false hits. Two were found and fixed: "mission" matching "commissions", and the boilerplate leaking into results.
  7. Built this chart as a single self-contained HTML file, and checked it on desktop and mobile.

Skill ranking

The score (0–10) weights each mention by where it appears: required qualifications ×1.0, role description ×0.75, nice-to-have ×0.5. The top skill is set to 10. % is the share of the analyzed jobs that mention the skill at all, shown as the thin dark line under each bar. Tiers: Must-have score ≥ 6 · Core 3–6 · Differentiator 1.5–3 · Niche < 1.5
