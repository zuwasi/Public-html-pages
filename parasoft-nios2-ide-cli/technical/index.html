DTP and credentials · 05

Keep credentials private and licensing explicit

DTP may provide the network license without receiving any analysis results.

# Private localsettings file, placeholders only
dtp.url=https://dtp.example:8443
dtp.user=<user>
dtp.password=<Parasoft-encoded-password>
cpptest.license.use_network=true
license.network.url=https://dtp.example:8443
license.network.use.specified.server=true
license.network.auth.enabled=true
license.network.user=<user>
license.network.password=<Parasoft-encoded-password>
# Only when it matches the purchased license:
cpptest.license.network.edition=automation_edition
Review and accept the EULA before setting parasoft.eula.accepted=true. Use cpptestcli -encodepass <password> in a private console; encoded passwords are not a substitute for restricted Windows file permissions.
Source: template localsettings example and successful encoded-password license tests, 24 November 2026. The runner does not pass -publish.
Compiler and rules · 06

A successful scan is not proof of full compiler qualification

The reference setup uses Nios GCC 4.9.2 with the gcc_7 analysis configuration as a documented approximation.

Compiler boundary

No exact Nios II GCC 4.9 preset was available. Autodetection fails for this toolchain. Validate target types, ABI and extensions with Parasoft before production use.

Known type-model caveat

The reference comparison found a long double size mismatch: 12 versus 8 bytes. Do not treat this integration demo as a qualified safety or compliance toolchain.

Measured fix loop · 10

Two fixes remove two findings, two remain

Free the allocated buffer and make the demonstrated pointer path non-null, then trace and analyze again.

4 before
Array bounds, uninitialized value, null pointer and memory leak
2 after
Array bounds and uninitialized value remain intentionally unfixed

The leak correction

Release buffer with free(buffer) after its last use and before returning. Re-analysis removes the memory-leak finding.

The pointer correction

The demo changes the call to find_optional_value(1). A production fix must handle the application’s full nullable-input contract, not just force this example path.

The video starts with three findings, adds the leaking function to reach four, then applies the two fixes to reach two. The handover demo sources were restored after recording.

Troubleshooting · 11

Separate environment, licensing and analysis problems

Start with the first failing stage and inspect the corresponding run log.

No compiler calls captured

Use a clean build. Confirm the actual compiler executable matches the trace filter, and run environment setup before make.

License or rules rejected

Check server reachability, private credentials, edition and entitlement. A listed rule set can still require an unavailable feature.

IDE symbols unresolved

Restart an IDE left open before the indexer settings changed. Then use the project’s Index > Rebuild action.

Dashboard port already used

Read the printed URL. The dashboard tries the next free loopback port rather than taking over another process’s port.

Keep IDE and CLI builds serialized in a shared tree. For simultaneous builds, use separate build outputs or separate worktrees with consistent saved sources.
