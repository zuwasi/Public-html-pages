Questions that become explicit requirements

  • Is the input an eigenstate?A superposition can produce multiple phase peaks.
  • Can the phase fit in m bits?Only an exactly representable phase has a certain ideal outcome.
  • What is being verified?A numerical model, an implementation, a theorem, or a physical device are different claims.
  • What does extra precision cost?Repeated controlled-U requires 2ᵐ − 1 applications.

03 / Normalize the mathematics

Make the model small enough to inspect.

The mathematical contract

U|u⟩ = e2πiφ|u⟩

φ is a fraction of a full turn, not an angle in radians. With N = 2ᵐ, outcome y represents phase y/N, modulo one.

p(y) = | N⁻¹ ∑x=0N−1 e2πix(φ−y/N) |²

Independent browser oracle: the squared sine ratio obtained from the finite geometric series, with the removable singularity handled explicitly.

The actual simulated system

One target qubit with a diagonal unitary:

U = diag(e2πiφA, e2πiφB)

Single eigenstate: target |0⟩.
Superposition: √w |0⟩ + √(1−w) |1⟩.

The browser evolves the joint state using Hadamard gates, controlled powers, swaps, and inverse-QFT controlled-phase gates. It sums over the target qubit to obtain the displayed marginal.

Important: the demo supplies the phases to construct U. It illustrates and checks QPE; it does not discover a secret phase or demonstrate a quantum speedup.

05 / Verification that can say no

A useful test must catch a plausible mistake.

Start with 3/8 and three estimation qubits. Each mistake below changes the simulated distribution while the independent reference remains unchanged.

FAULT / FOURIER SIGN
011 → 101

Use QFT instead of inverse QFT

The sign error sends phase 3/8 to 5/8. The result is sharply peaked, but wrong. A clean-looking chart is not sufficient evidence.

FAULT / BIT ORDER
011 → 110

Reverse the output bits

The same bits become a different number: 6/8 instead of 3/8. Asymmetric test inputs expose an error that 000 or 111 would hide.

FAULT / CONTROLLED POWER
U⁴ → I

Omit the largest power

One qubit no longer accumulates its required phase. The probability distribution disagrees with the reference and the gate blocks a pass.

A fault can be invisible for special inputs, such as zero phase. This is why the test suite uses many phases rather than relying on one successful run.

What has actually been established?

The repeated-U cost assumes powers are built by repetition. This toy diagonal unitary permits direct phase rotations, so the count is not this simulator’s wall-clock cost or its compiled gate count.
